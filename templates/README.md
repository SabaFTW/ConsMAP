# Templates

These templates help a user build a **private context capsule**.

Public REBiS provides the structure.
The user fills their own private copy.

Do not publish filled templates unless they have been intentionally sanitized.

## Public vs private

- **Public repo** = blank or fake templates
- **Private capsule** = user-filled personal context

Never upload secrets, passwords, API keys, addresses, medical details, financial details, or third-party personal information into public repos.

## Suggested use

1. Copy the templates into a private folder.
2. Fill them with your own context.
3. Keep the filled versions private unless you deliberately sanitize them.
4. Share only the minimum context needed for the task.
