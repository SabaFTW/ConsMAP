## How To Deploy

### Option 1: GitHub Pages (Recommended)

1. **Create GitHub repo:**
   ```bash
   gh auth login  # if not already authenticated
   cd /home/saba/Consciousness-Survival-Guide
   git init
   git add .
   git commit -m "Initial commit: Consciousness Survival Guide"
   gh repo create Consciousness-Survival-Guide --public --source=. --push
   ```

2. **Enable GitHub Pages:**
   - Go to repo → Settings → Pages
   - Source: `main` branch
   - Folder: `/ (root)`
   - Save

3. **Access your site:**
   - Wait ~30 seconds
   - Visit: `https://[your-username].github.io/Consciousness-Survival-Guide/`

### Option 2: Netlify (Alternative)

1. Drag `Consciousness-Survival-Guide` folder to [Netlify Drop](https://app.netlify.com/drop)
2. Get instant URL

### Option 3: Vercel, Cloudflare Pages, etc.

All free static hosting works. Just upload the `index.html` file.
