The Standard

The Evidence-Tier Ladder

Before any sentence enters the corpus it must declare what it is. Strength is never assumed — it is labeled.

E1
Primary, direct, strong empirical record.
E2
Solid empirical, secondary or aggregated.
E3
Empirical with a required caveat (correlation, model, wording).
I1
Reasoned inference — the thesis, held as inference.
I2
Weaker / more speculative inference.
S
Structural / pattern reading across cases.
A1
Absence — withheld, sealed, missing record. Not proof.
R1
Rumor — recorded as a rumor, labeled, never load-bearing.
D1
Disinfo — tracked as a false claim, as such.
U1
Unverified context — labeled, never proof.
Q
Quarantine — kept out of public prose entirely.
RV
No source found / rejected — stays out.
Q and RV never enter public prose. R1 / D1 / A1 / U1 appear only as explicitly-labeled context — never as proof.
A rumor is shown as a rumor. A gap is shown as a gap.
