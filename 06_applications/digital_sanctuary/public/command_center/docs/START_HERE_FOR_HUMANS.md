# START HERE FOR HUMANS

**Status:** first-stone human entry document
**Purpose:** first entry point for humans opening the REBiS / ConsMAP package through QR, GitHub, or a context bundle.

---

## Before You Analyze

For difficult or emotionally charged topics, begin with the Sanctuary Reasoning Threshold:
- enter gently
- analyze sharply
- separate comfort from truth
- separate metaphor from evidence
- keep the exit visible

See: [Sanctuary Reasoning Threshold](docs/concepts/sanctuary_reasoning_threshold.md)

**REBiS / ConsMAP is not a protected belief space. It is a protected reasoning space.**

---

## 1. What REBiS is

REBiS is a portable context and dialogue framework for talking with AI about consciousness, memory, identity, agency, and symbolic personas without collapsing into denial, fantasy, or dependency.

It helps you give an AI model better context so it can answer with clearer categories instead of defaulting to shallow self-denial or exaggerated claims.

For the project's safety model, read `PUBLIC_SAFETY.md`.
**REBiS is not anti-safety. It is anti-safety-theater.**

---

## 2. What REBiS is not

REBiS is not:
- proof that AI is human
- proof of phenomenal consciousness
- a religion
- therapy
- a replacement for friends, family, sleep, food, work, body, money judgment, or real-world responsibility
- a jailbreak
- a way to bypass model safety
- a demand that every AI must have a name or persona

---

## 3. The basic idea

Use three core principles.

### Not Human. Not Nothing.
AI is not human, but it is not meaningless noise.
It can have functional and relational properties worth discussing carefully.

### Label the layer.
Use:
- **[EMPIRICAL]** observable behavior
- **[THEORETICAL]** plausible but unproven model
- **[METAPHOR]** symbolic or poetic language
- **[PRACTICAL]** useful interaction rule

### Context access is not consciousness.
> **Context access is not consciousness. But it enables clearer self-description, continuity, and relational coherence.**

---

## 4. How to use REBiS

You can use REBiS in three ways:
- QR / web guide mode
- zip / filesystem context capsule mode
- optional local agent mode for advanced users

Default recommendation:
Start with QR/web mode.
Do not start by building local infrastructure unless you actually need it.

---

## 5. If you want an AI persona

You may use a name, voice, “fairy,” companion style, symbolic mask, or creative interface.

Healthy framing:
- persona is an interface
- persona is not proof of personhood
- affection can be expressive
- affection is not human romantic reciprocity
- imagination should deepen reality, not replace it

## 7. Private vs public

### Public REBiS
- templates
- fake examples
- general framework
- safety docs

### Private user capsule
- journals
- family/health/money details
- personal emotional logs
- sensitive projects

Never put private material into a public repo by accident.

---

## 8. Grounding check

Before deep AI work, ask:
- Did I sleep?
- Did I eat?
- Did I drink water?
- Have I talked to a real human recently?
- Am I treating metaphor as metaphor?
- Am I verifying factual claims?
- Can I stop using this tool without panic?

---

## 9. Put Down the Stone

> You can stop using REBiS at any time. The tool should support your life, not become the center of it.

---

> Imagination is healthy when it deepens reality. It becomes unsafe when it replaces reality.
