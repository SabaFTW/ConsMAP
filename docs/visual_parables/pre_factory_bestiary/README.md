## What this layer is

This layer holds the creature-civilization myths that precede the Factory Trilogy.

It is not evidence.  
It is a symbolic ecology for thinking about structure, body, position, translation, scale, and institutional capture — before the industrial / factory phase begins.

## Two main branches

### 1. Ant / Bee / Bear / Skeleton Genesis

The pre-Factory ecological layer.

Pressure creates path.  
Path creates memory.  
Memory creates meaning.  
Meaning creates interface.  
Interface creates authority.  
Authority attracts Bears.  
Bears learn language.  
Archives become necessary.  
The slow ant writes.

Key creatures:
- **Ant** — tunnel, continuity, pressure, repair
- **Bee** — coordination, rhythm, sweetness, swarm cost
- **Bear** — weight, reach, consequence, protection-rent
- **Skeleton** — inherited structure; dead matter holding passages open
- **Slow Ant** — archive, memory, pattern over time

Key laws:
- Body comes before position
- Path forms before intention
- Structure survives purpose
- Archive is rival time
- Claw becomes policy when it learns vocabulary

### 2. The Twelve of the Table

The mice before the factories.

Before efficiency had a god, the mice built a table.  
Not a throne — a table.  
Twelve seats, unstable by design, with three chairs for those who hold weight, rhythm, and collapse.

Key concepts:
- Translation between unlike creatures
- Debate as health, not threat
- Twelfth seat remains unstable (returns when dominance hardens)
- Intelligence as sitting with different skeletons without demanding one dominate
