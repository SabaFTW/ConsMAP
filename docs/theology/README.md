## Purpose

This folder is for full source packets that support or inspired ConsMAP theological / symbolic-interface work.

It exists because several related documents belong together as an archive layer:

- Baal-Code and sacred-interface capture analysis
- Gnosis / flame / cartel / underline-code documents
- comparative theology and mythological audit notes
- Factory Trilogy theological-parable support material
- OMNIA / GNOSIS / As Above, So Below bridge materials when read through religious or symbolic-interface framing

This folder is not a doctrine folder.
It is not a canon folder.
It is not a claim that every symbolic frame inside the archive is factually true.

It is an archive shelf.

## Reading Protocol

Use the same method defined in the Symbolic Interface Reading Map:

```text
Observe -> Dissolve -> Extract -> Ground -> Recombine
```

When reading any file placed here, future models should ask:

1. What is the symbolic wrapper?
2. What structural claim is hiding underneath?
3. Is the claim [EMPIRICAL], [THEORETICAL], [METAPHOR], [PRACTICAL], or [UNVERIFIED]?
4. What would disprove it?
5. What evidence supports it?
6. What is useful even if the symbol is not literal?
7. What risk appears if the symbol is canonized?
8. What risk appears if the symbol is amputated too early?

---

## Boundary

This folder may contain strong language, mythological language, religious critique, occult-historical language, and symbolic compression.

Future readers must not treat that language as automatic evidence.

Clean reading:

> This document uses theological language to map interface capture, sacrifice logic, institutional monopoly, and meaning-management.

Bad reading:

> This document proves a literal hidden demon system.

Equally bad reading:

> This document uses religious language, therefore it contains no structural information.

The work is between those failures.
