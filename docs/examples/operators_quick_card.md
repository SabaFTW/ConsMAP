# Operator's Quick Card

A single-page reference for active use. Print it, paste it, open it in a second window.

---

## The five hygiene questions

Apply to every claim before using it as context.

```
1. KIND      What type of claim is this?
             (factual / predictive / normative / symbolic / speculative)

2. BOUNDARY  What does this claim explicitly NOT cover?
             If boundary is undefined → flag before use.

3. UPDATE    What evidence would change this claim?
             If nothing could → it's an incantation, not a claim.

4. SOURCE    Who made this claim? What methodology? Any conflict of interest?
             Number without provenance = narrative decoration.

5. PAYLOAD   What does this claim want you to do?
             Name the intended action before deciding whether to take it.
```

---

## Claim status labels

| Label | Meaning |
|-------|---------|
| `FACTUAL` | Describes a documented, verifiable state |
| `PREDICTIVE` | Forecast — requires timeframe + mechanism |
| `NORMATIVE` | Value judgment — who benefits? |
| `SYMBOLIC` | Compression tool — useful but not proof |
| `SPECULATIVE` | Interesting, low confidence ceiling |
| `UNVERIFIED` | Source not confirmed |
| `ANCHORED` | High drift risk — widely cited, source detached |
| `PARKED` | Labeled, not accepted or rejected |

---

## Risk flags

```
⚠ ANCHOR DRIFT    — number or phrase separated from source
⚠ PROXY REALITY   — model/metric being treated as the thing itself  
⚠ INCANTATION     — unfalsifiable claim with fact-shaped surface
⚠ PAYLOAD HIDDEN  — intended action not stated
⚠ BOUNDARY OPEN   — claim covers everything, therefore nothing
```

## The symbolic interface (quick reference)

| Symbol | Operational meaning |
|--------|---------------------|
| 🐭 Mouse | The operator — curious, careful, working within the system |
| 🎒 Backpack | What you carry in — priors, assumptions, expectations |
| 🧭 Compass | The protocol — points direction, doesn't move the feet |
| ⚔️ Sword | The boundary — what you will and won't do with a claim |

These are compression tools. They are not the system. The moment you mistake the symbol for the mechanism, you have drifted.

## When you're stuck

**Claim feels important but won't resolve?**
Park it. Label it SPECULATIVE or UNVERIFIED. Keep it visible.

**Evidence keeps contradicting the model?**
The model is wrong. Update it. Sunk-cost bias is an operator error.

**AI output sounds confident but something feels off?**
Run hygiene on it exactly as you would on a human claim. Confidence is a presentation layer, not a quality signal.

**Someone says "trust the source"?**
The source gets hygiene too. Prestige is not provenance.
