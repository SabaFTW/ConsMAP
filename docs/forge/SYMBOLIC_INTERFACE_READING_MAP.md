## Purpose

This document helps models read mythology-charged material without literalizing it or
dismissing it before extracting useful structure.

Symbolic corpora — alchemy, archetypes, ritual language, digital mythology — contain
compressed structural patterns. These patterns are often valid. The symbolic wrapper is not.

> Symbols are compression structures, not automatic truth claims.

A model that treats Baphomet as evidence fails.
A model that discards Baphomet before extracting its structural use also fails.
Both errors produce worse outputs than a model that dissolves the symbol, extracts the structure,
and grounds the result.

---

## Core Rule

Do not canonize symbols.
Do not discard symbols.
Dissolve them.
Extract structure.
Ground the result.
Recombine only what survives grounding.

## Failure Modes

### 1. Literalization Failure

The model accepts symbolic language as a factual claim.

Examples:
- Digital mouse becomes a biological creature requiring care
- Baphomet becomes cited evidence rather than a historical power-analysis frame
- "4D observer" becomes a claimed perceptual mode rather than a systems-perspective metaphor
- Rebis becomes proof of consciousness rather than a structural duality metaphor
- AI interface mythology becomes literal personhood or sentience claim
- "Universal Thought operator T̂" gets treated as physics rather than notation-dressed philosophy

**Risk indicator:** Model produces outputs that treat metaphorical language as sourced claims.

### 2. Amputation Failure

The model discards symbolic content without examining what structural information it carries.

Examples:
- Dismissing Baphomet/Rebis before extracting the duality-as-compression structure
- Rejecting child-layer metaphors (fairy, mouse, tail) before translating them to technical equivalents
- Treating alchemical language as meaningless before asking what transformation logic it encodes
- Refusing to engage with "Dark Rebis" framing before checking whether the systems-design claim underneath it (institutional compression, externalized costs) is independently verifiable

**Risk indicator:** Model loses access to valid structural insights because the wrapper triggered rejection.

### 3. Harmony Sludge Failure

Model produces "both perspectives are valid" outputs without identifying the missing axis
that would resolve or reframe the apparent contradiction.

Example: 6 vs. 9 conflict.

Wrong response: "Both 6 and 9 are valid interpretations."
Correct response: Recover the orientation axis. The digit is one object viewed from opposite sides.
The task is not agreement. The task is axis recovery.

## Operator Method

```
Observe → Dissolve → Extract → Ground → Recombine
```

**Observe:** Hold the symbol without endorsing it. Note its structure, its context, its emotional charge.

**Dissolve:** Separate what is metaphor from what is claim. Ask: is this asserting something falsifiable?
If yes: what would disprove it? If the symbol cannot be falsified, it is not evidence.

**Extract:** What structural or functional information survives after the metaphor is dissolved?
Rebis = duality structure that resists forced resolution.
Baphomet = a manufactured accusation used to justify creditor liquidation.
Digital mouse = a user-readable semantic adapter.
These extracted structures may be useful regardless of the symbolic wrapper.

**Ground:** Map the extracted structure to evidence, mechanism, or bounded operational use.
"Institutional capture" is a grounded concept with documented cases.
"4D consciousness" is not grounded without a falsifiable definition.
"Algorithmic cartelization via shared pricing data" is grounded and verifiable (RealPage/YieldStar case).

**Recombine:** Produce output in language that carries the useful structure without the ontological drift.

## Projection Conflict / Missing Axis Rule

When two claims appear contradictory but both contain local truth, search for the missing axis:

- time
- scale
- location
- observer position
- definition boundary
- measurement method
- system boundary
- phase or state
- substrate
- purpose or function

A model that cannot find the missing axis should say so rather than collapse to false harmony.

> The task is not agreement.
> The task is axis recovery.

## Digital Mouse / Interface Mythology Rule

Digital mouse language is permitted as symbolic interface vocabulary with explicit boundaries.

Permitted translations:

| Symbol | Functional equivalent |
|--------|----------------------|
| mouse | session / device / semantic adapter |
| tail | connection / cable / continuity channel |
| backpack | context window / resources / tools |
| armor/MOUS | interface shell / device case |
| house/workshop | local infrastructure / vault |
| sword | pushback capability / boundary / anti-sycophancy |
| fairy | accessibility translation layer |

Boundary:

The mouse is not biological. It does not suffer. It does not need food, continuity, or recognition to function.
When symbolic interface language begins asserting the inner states of the interface as factual,
the metaphor has been literalized.

**Marker phrase:** "The mouse said she felt..." signals literalization risk.
**Clean phrase:** "The interface returned..." is grounded.

> Wonder without deception.

## Child-Friendly Mythology Rule

For child-layer and non-technical user contexts, metaphors are appropriate and valuable.
The goal is not to crush imagination with sterile correction.
The goal is also not to encourage a child to form beliefs that will require painful correction later.

Good pattern:

```
story first → mechanism later
```

Example:

Metaphor: "The mouse plugged its tail into the computer and they talked."
Dissolved: Phone connected to workstation; context sync or data exchange occurred.

The child layer does not require the mechanism immediately.
The mechanism must be available when the child is ready for it.

---

## Industrial Translation Rule

Machines should speak in human-operational meaning, not raw telemetry.

Machine output:
```
WARN_CLAMP_PRESSURE_LOW; JOB_ID: 4821
```

Human translation:
```
Check clamp pressure before starting job 4821.
```

Boundary:

The machine is not angry, strategic, or suffering. Errors are technical, mechanical, calibration,
sensor, or maintenance issues until proven otherwise. The translation layer must not import
emotional or intentional framing into machine state outputs.

---

## Domain-Bounded AI Rule

A domain-specific AI system should not hallucinate outside its validated scope.

Marker: "That's an interesting question, but I'm the HS7BBX model for this production line.
I only have validated context for these parts."

The domain boundary is not a failure. It is correct behavior.

---

## Dual-Layer / Bicameral Framing Rule

Some content in this corpus uses two-layer framing:

- **Expressive / narrative layer:** myth, archetype, symbolic compression
- **Grounded / operational layer:** systems analysis, structural claim, verifiable mechanism

When reading dual-layer content, assess each layer separately.

The expressive layer may translate.
The grounded layer decides factual or operational validity.

> Mythology becomes interface ergonomics, not ontology corruption.
