# FORGE

FORGE is file management for engineers that learns how you actually work.

Not how a manager imagines you work.  
Not how a PDM consultant says you should work.  
How you actually work.

---

Most engineering file systems create friction:

- forced metadata  
- rigid folder structures  
- approval bottlenecks  
- naming rules nobody follows  
- hidden workarounds in Excel, Dropbox, `/TEMP`, and `final_FINAL_v3`

FORGE starts from the opposite assumption:

Engineers do not need more control systems.  
They need a system that reduces drag without stealing judgment.

## How it works

You save a file.

FORGE looks at context:

- file type  
- project structure  
- naming patterns  
- related assemblies  
- your previous decisions  

Then it suggests:

- tags  
- folders  
- release status  
- related files  
- cleanup actions  

You choose.  
FORGE learns from that choice.

Next time, the suggestion gets better.

## The rule

FORGE suggests.  
You decide.

No forced metadata before saving.  
No punishment for messy work-in-progress.

Chaos is not the enemy.  
Untraceable chaos is.

## Why it matters

Classic PDM systems make engineers work for the database.

FORGE makes the database learn from the engineer.

Result:

- less admin  
- less searching  
- fewer fake compliance rituals  
- more actual engineering

## What it is not

FORGE is not magic AI.

It does not replace engineering judgment.  
It does not fix broken teams automatically.  
It does not solve every compliance problem by itself.

In highly regulated environments, it needs stronger guardrails.

That is not a weakness.  
That is honesty.
