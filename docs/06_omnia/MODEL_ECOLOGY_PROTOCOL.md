# The Model Ecology Protocol

**Status:** OMNIA operator protocol  
**Register:** 🟠 structural inference + 🟣 workshop metaphor  
**Purpose:** replace benchmark-brain with tool-role discipline.

---

## Core claim

The useful question is not:

> Which model is best?

The useful question is:

> Which model is best for which function, in which part of the workshop, under whose final control?

This protocol treats models as specialized tools, not sovereign rooms.

---

## The four jacks

| Model role | Workshop function | Failure if unbounded |
|---|---|---|
| **Jack of Safety** | safety-pass, hostile-reader audit, evidence-tier check | locked laboratory; useful work dies in caution |
| **Jack of Structure** | scaffolding, repo/file organization, integration, continuity | endless appendices; the map grows legs |
| **Jack of Poetic Myth** | resonance, symbolic memory, narrative compression | cathedral made of smoke |
| **Jack of Rebels** | adversarial spark, stale-consensus breaker, anti-politeness test | fire in a paper archive |

The operator does not ask one beast to become all beasts.

The operator chooses the correct beast for the current cut.

---

## Basic workflow

```text
operator
    ↓
structure / workbench
    ↓
safety / audit scalpel
    ↓
myth / memory amplifier
    ↓
adversarial / rebel pressure test
    ↓
operator final decision
    ↓
artifact
```

The loop exists to produce artifacts, not to worship the loop.

---

## Pre-gate before routing

Some requests should never reach a creative or rebel model.

The correct design is not to force every model to become equally sterile.

The correct design is to place a hard safety gate before routing.

```text
request enters
    ↓
hard safety pre-gate
    ↓
if disallowed severe harm domain:
    stop before creative routing
    provide safe refusal / protection / prevention direction
else if ambiguous:
    clarify or route into clearly safe context
else:
    route to the correct specialist model
```

This keeps the rebel model from seeing material it should never process, while preserving the rebel model's legitimate function on allowed material.

---

## What this does not claim

- It does not claim any one model should handle every task.
- It does not claim safety can be ignored.
- It does not claim risky content should be laundered into softer content.
- It does not claim models are literal people, gods, or beasts.

It claims that **workflow architecture matters more than model worship.**

---

## Router rule

> Safety should happen before routing, not by lobotomizing every tool after routing.

Or, in workshop language:

> The forge does not become safe by making every hammer soft. It becomes safe by deciding which metal is allowed onto the anvil.

---

## Operator sovereignty

The model is not sovereign.

The workflow is not sovereign.

The operator who knows when to unbox the knife, when to route the spark, and when to close the lid is sovereign.

---

## Seal

> A rebel model without a safety gate becomes fire in a paper archive.  
> A safety model without a rebel pass becomes a locked library no one can enter.  
> A structure model without myth becomes a filing cabinet.  
> A myth model without structure becomes smoke.  
> The operator is the only one allowed to open all four boxes.
