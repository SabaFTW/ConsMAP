# OMNIA Register Rules

**Status:** working protocol  
**Purpose:** prevent symbolic writing from impersonating evidence, and prevent evidence from becoming so dry that nobody remembers it.

---

## The central failure mode

Most public critique fails in one of two ways:

1. **Dry truth dies:** the evidence is accurate, but no one remembers the mechanism.
2. **Hot myth snaps:** the metaphor is memorable, but hostile readers can dismiss it as fantasy.

OMNIA is built to avoid both failures.

---

## The rule

> Myth remembers. Evidence proves. Never the same uniform.

Every claim must know what kind of claim it is.

---

## Registers

| Register | Label | What it means | Can it carry load? |
|---|---|---|---|
| Confirmed reporting | 🟢 | Named source, dated, attributable, checkable. | Yes. |
| Checkable unresolved | 🟡 | Searchable or testable, but not yet verified. | No. |
| Structural inference | 🟠 | Argument built from confirmed facts. | Yes, if clearly labeled as argument. |
| Mythic illustration | 🟣 | Literary compression, parable, symbolic memory. | No factual load. |
| Quarantine | ⚫ | Unsupported, unsafe, malformed, or too easy to snap. | No. |

---

## How to use the registers

### 🟢 Confirmed reporting
Use for hard floor claims.

Required fields:

- source / outlet
- date
- actor
- exact claim
- why it matters structurally

Example:

> [🟢] Outlet X reported on Date Y that Institution Z did Action A.

### 🟡 Checkable unresolved
Use for claims that may be true but are not ready.

Allowed language:

- checkable
- unresolved
- pending source
- hypothesis awaiting verification

Forbidden language:

- confirmed
- proved
- documented
- exposed

### 🟠 Structural inference
Use for arguments.

Example:

> If access is restricted to powerful institutions while risk remains public, then containment has not removed danger; it has relocated danger upward.

This is not reportage. It is reasoning.

### 🟣 Mythic illustration
Use for memory.

Examples:

- Baphomet = dual-use symmetry
- Saturn = power consuming its own future
- Nephilim = authorized giant capability
- Megalodon Cow = harmless thing made predatory by scale

Mythic symbols can name a pattern.
They cannot prove the pattern.

### ⚫ Quarantine
Use for material that should not carry the argument.

Quarantine when:

- no source can be found
- wording is too hot for the evidence
- metaphor is pretending to be fact
- the claim depends on motive-reading
- a hostile reader could pull one loose thread and unravel the section

---

## Reader defense rule

Each major OMNIA chapter should contain a short section called:

## What This Does Not Claim

This prevents cheap dismissal.

Example:

- This does not claim every safety framework is fraudulent.
- This does not claim all restricted access is malicious.
- This does not claim myth is evidence.
- It does claim that restricted access can become capability concentration when the public bears the risk but cannot audit the tool.

---

## Exit rule

If a metaphor becomes more important than the evidence, stop.

If a source contradicts the mythic frame, revise the frame.

If the facts are strong enough, they do not need costume armor.

---

## One-line seal

> The symbol may carry the memory. Only the source may carry the charge.
