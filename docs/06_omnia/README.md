# OMNIA Section

**Status:** public-facing synthesis shelf / manuscript bridge  
**Role:** connects OMNIA, the Baphomet Engine, the Nephilim Papers, and ConsMAP claim-hygiene architecture without collapsing myth into evidence.  
**Rule:** Myth remembers. Evidence proves. Never the same uniform.

---

## What this section is

The OMNIA section is a bridge between symbolic long-form writing and ConsMAP's evidence discipline.

It exists because some patterns are too dry to survive memory if they are written only as audit tables, and too vulnerable to hostile reading if they are written only as myth.

OMNIA holds both layers separately:

- **Court layer:** sourced claims, evidence ledgers, named outlets, confidence tiers.
- **Memory layer:** Baphomet, Saturn, Nephilim, the Megalodon Cow, Mario, and other symbolic compression engines.

The point is not to make mythology factual.

The point is to make structural facts memorable without letting the symbols pretend to be evidence.

---

## What this section is not

OMNIA is not:

- a religion
- proof of occult causality
- proof that AI systems are literal demons, giants, or gods
- a replacement for sourcing
- an excuse to treat metaphor as evidence
- a shortcut around ConsMAP claim hygiene

If a sentence makes a factual claim, it must be routed through evidence discipline.

If a sentence is mythic, it must remain visibly mythic.

## Five-register method

OMNIA uses the same discipline that should protect the wider ConsMAP project:

| Register | Meaning | Use |
|---|---|---|
| 🟢 Confirmed reporting | Hard factual floor | Named outlet, date, claim, why it matters. |
| 🟡 Checkable / unresolved | Needs verification | Hold out of the load-bearing floor. |
| 🟠 Structural inference | Argument over facts | Label as reasoning, not reportage. |
| 🟣 Mythic illustration | Literary compression | Memory layer only; not evidence. |
| ⚫ Cut / quarantine | Unsafe or unsupported | Remove, rewrite, or park until sourced. |
