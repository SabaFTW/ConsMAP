# ConsMAP Classics Archive

This folder preserves longer-form research artifacts that informed the ConsMAP framework.

These documents are not treated as canonical proof.
They are treated as source atlases, metaphor engines, and diagnostic surfaces.

Use them as:

- background research
- pattern libraries
- archetype references
- examples of structural analysis
- prompts for future claim maps

Do not use them as:

- automatic evidence
- sacred doctrine
- unfalsifiable authority
- replacement for claim hygiene

Core rule:

> Preserve the classics without letting them become cages.

Every artifact in this archive should remain optional, inspectable, and revisable.

If a document becomes mandatory belief, it has switched from map to trap.
